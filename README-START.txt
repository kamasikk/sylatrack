FITMIND — ШВИДКИЙ ЗАПУСК

1. Розархівуй ZIP у будь-яку окрему папку.
2. Відкрий цю папку.
3. Двічі натисни Start-FitMind.bat.
4. Браузер відкриється автоматично.

Не відкривай index.html подвійним кліком — так не запрацює серверна авторизація.
Не запускай node server.js з папки Downloads, якщо там немає server.js.

Щоб зупинити сайт: у чорному вікні натисни Ctrl + C.

GEMINI (НЕОБОВ'ЯЗКОВО)
AI-тренер уже має локальні поради. Щоб він відповідав через Gemini, створи ключ у Google AI Studio
та у цій же папці створи файл .env (без розширення). Встав у нього один рядок:
GEMINI_API_KEY=твій_ключ
Ключ не вставляй у index.html або app-fixed.js і не надсилай його в чат. Після зміни перезапусти сервер.
Або двічі натисни Add-Gemini-Key.bat, встав ключ один раз і надалі користуйся Start-FitMind.bat.

EMAIL І ПУБЛІКАЦІЯ
Локальна версія перевіряє формат email, але не може довести, що скринька належить користувачу без надсилання листа.
Перед публікацією на Netlify підключимо Firebase Authentication: він надсилатиме лист для підтвердження email і надійно зберігатиме акаунти.
