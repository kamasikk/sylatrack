# FitMind

Персональний трекер тренувань українською: акаунти, журнал сесій з кількома вправами та сетами, аналітика, календар, відновлення м’язів, улюблені вправи й AI-тренер.

## Локальний запуск

Потрібен Node.js 20 або новіший.

```powershell
node server.js
```

Відкрий адресу, яку покаже термінал (зазвичай `http://localhost:4173`). На Windows можна просто двічі натиснути `Start-FitMind.bat`.

Не відкривай `index.html` подвійним кліком: авторизація та AI-тренер потребують сервера.

## Gemini для AI-тренера

1. Створи файл `.env` поруч із `server.js`.
2. Додай один рядок: `GEMINI_API_KEY=твій_ключ`.
3. Перезапусти сервер.

Ключ читається тільки сервером і не потрапляє у браузер. Файл `.env` та локальна база `fitmind-db.json` уже виключені з Git через `.gitignore`.

## Важливо перед публікацією

Ця версія зберігає користувачів у локальному JSON-файлі, тому підходить для запуску на одному сервері, але не для масштабованого публічного сервісу. Для Netlify/Firebase наступним кроком треба перенести авторизацію та дані у Firebase Authentication і Firestore. Локальна перевірка email перевіряє формат адреси; реальне підтвердження пошти потребує сервісу надсилання листів або Firebase Auth.
